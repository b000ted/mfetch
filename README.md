# mfetch

A fork of a fork. mfetch is a macOS / Darwin port of [gfetch by kantiankant](https://github.com/kantiankant/gfetch).

## build

requirements:

- A C11 compiler
- Xcode Command Line Tools

clone:
```sh
git clone https://github.com/b000ted/mfetch
cd mfetch
```

build:
```sh
make
```

run:
```sh
./mfetch
```

install:
```sh
sudo make install
```

run:
```sh
mfetch
```

uninstall:
```sh
sudo make uninstall
```
removing the compiled binary from the project directory:
```sh
make clean
```
